# Система идентификации аномальной активности в приложениях на основе анализа текстовых логов

Программная система для автоматического выявления аномальной активности в приложениях на основе анализа текстовых логов с использованием методов машинного обучения и глубокого обучения.

## Используемые технологии

- Python 3.10+
- NumPy
- Pandas
- Scikit-learn
- TensorFlow / Keras
- Drain3
- Matplotlib
- Seaborn
- Joblib

## Установка

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/Roman-NS/my-diplom
cd REPOSITORY
```

### 2. Установите зависимости

```bash
pip install -r requirements.txt
```

---

## Подготовка данных

Для работы проекта необходимо загрузить набор логов HDFS.

```
https://www.kaggle.com/datasets/platform934/hdfs-log-dataset

hdfs.log
```

Логи не включены в репозиторий из-за большого объёма данных.

---

## Запуск проекта

### Обучение модели Isolation Forest

```bash
python if_training.py
```

В результате будут сохранены:

- модель Isolation Forest;
- TF-IDF-векторизатор;
- параметры масштабирования признаков.

---

### Обучение модели LSTM Autoencoder

```bash
python lstm.py
```

В результате будет сохранена обученная нейросетевая модель, а так же сразу произведён анализ лога.

---

### Анализ логов при помощи Isolation Forest

```bash
python if.py
```

Скрипт загружает сохранённую модель и выполняет анализ нового лог-файла.

---

### Ансамблевое объединение моделей

```bash
python ensembled.py
```

Скрипт загружает модели Isolation Forest и LSTM Autoencoder, анализирует лог и формирует итоговую оценку аномальности.
